How to add notes

Method 1: Manual Notes
  • Right-click any word or highlight a phrase in the subtitles and choose Add manual note from the context menu.
  • Click the + button in this dialog to add a note for any custom term manually.
Method 2: Offline Dictionary
  • Make sure offline dictionary is configured in global settings for currently selected language of the project.
  • Hover over a word to open the dictionary popup.
  • Select any text inside the definition.
  • Right-Click → Add to Notes (or Press Ctrl+Shift+S).
Method 3: Online Lookup
  • Click a word to open the built-in browser.
  • Select any text on the webpage.
  • Right-Click → Add to Notes (or Press Ctrl+Shift+S).
The new note will be saved under the original word/phrase that was selected from the subtitles.
