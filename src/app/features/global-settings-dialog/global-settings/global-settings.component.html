Uses GPU for video decoding. Can improve performance on modern PCs but may cause lagging or freezing on older hardware/drivers (especially with HEVC).
Recommended: Leave OFF unless you experience high CPU usage or lag on high-resolution videos. Enable only if your GPU supports at least native HEVC decoding.
This unified speed applies to the entire video when Cinema Mode is toggled on via the toolbar (or by pressing M).

Displays a visual waveform of the audio on the timeline.

Warning: This is slow process (e.g., ~1 minute for a 2-hour movie) that has to be done once per project.
It is recommended to keep this disabled for the fastest project loading.

If enabled, a waveform will be generated for any project that is loaded without one.
Disabling this setting will not remove waveforms from projects that already have them.
